API Overview

This API provides endpoints for the ZaZa Customer mobile application, enabling customers to browse restaurants, place orders, manage delivery addresses, and track deliveries in real-time.

Base URL (Dev)

http://localhost:8000/api/v1

Base URL (Prod)

https://api.zaza.tj/api/v1

Authentication

Bearer Token (JWT)

Response Format

JSON with standard error handling
